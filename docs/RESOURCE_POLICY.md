# 资源与授权边界

[返回首页](../README.md)

## MIT 覆盖什么

本仓库新实现的 Rust/Swift/Metal 代码、构建脚本和文档按根目录 [LICENSE](../LICENSE) 中的 MIT 许可证发布。第三方依赖各自适用其许可证；MIT 不会取代它们的义务。依赖版本见 `Cargo.lock`，发行二进制前应同时检查所带依赖及原生库的授权声明。

## 不包括什么

本项目不拥有或授予原作的游戏资源、剧本/对白、图片、角色、美术、音频、视频、字体、商标或名称权利，也不分发这些资源。原作及相关权利归各自权利人。本项目不是官方移植，不暗示得到原作方背书。

**使用本运行时前，必须自行合法取得且有权使用游戏资源。** 源码开源不等于游戏本体免费或资源可再分发。本仓库不提供资源下载、解密密钥、DRM 绕过或 Steam 访问控制替代方案。

## 提交与公开反馈规则

不得提交或上传：

- XP3 包、提取的原作 `.ks` / `.tjs` 脚本、游戏图片/音视频/字体、EXE/DLL。
- 原版或本运行时的用户存档、全局进度、QA checkpoint、私有测试录像。
- 账号密码、令牌、证书、签名私钥、provisioning profile、个人路径或敏感日志。

回归测试应在代码中合成最小资源和脚本。真实资源测试显式 opt-in，资源存放在仓库之外。公开 issue 优先附版本、归档顺序、资源文件名、脱敏错误和不含原作内容的最小复现；素材截图/录像须另行确认授权，不作为仓库的默认展示素材。

## 技术安全边界

归档以只读方式处理；检查路径、索引/segment 边界、解压长度与校验。受保护条目不支持，不提供解密。合法空 marker 仍须满足结构和校验，不以“兼容”名义放松检查。用户可显式跳过损坏片段，但不重写 XP3 或制造假媒体。
