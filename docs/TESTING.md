## UI 第一轮改进（2026-11-14，未递增发布版本）

- 标题页分为资源引导/可游玩状态，继续摘要使用与核心一致的兼容存档排序；阅读顶栏精简，增加隐藏/恢复界面。
- 隐藏仅在普通停页可用，先停止快进再检查资格；隐藏时仍绘制画面但不调用剧情 tick。第一次点击/空格/右方向键只恢复 UI，不提交剧情动作。错误、弹窗、切后台和显式导航恢复 UI，不自动重新隐藏。
- 新的对白组件与设置预览共享排版，支持不透明度、行距和可选页码；长文/说话人信息可滚动，操作按钮保持可达。大字号允许使用画面之外的留黑区域，不裁切场景。
- `scripts/check-native.sh --swift-only`：三 SDK Swift 6 严格类型检查、原有 19 条原生断言、219 条媒体策略断言、资源导入/路径测试及新增 184 条阅读策略/布局断言通过。**该选项明确不检查 Metal shader；默认命令仍执行完整检查。**
- `cargo fmt --check` 与默认 Rust 138 项测试通过；需要原作资源/GPU 的测试未启用。当前 Rust 1.95 的 Clippy 在未修改的 [coverage.rs](../src/coverage.rs) 上报告 `collapsible_match`，未将其当作通过或为 UI 修改抑制此 lint。

## 真实资源检查（必须自备）

资源只存放在仓库之外，运行前先备份用户存档；不要在公开 issue/CI 上传资源、存档或 QA checkpoint。

```sh
KOIKARI_ASSETS=/path/to/base KOIKARI_PATCH_ASSETS=/path/to/combined \
  cargo test --locked --release --test real_patch -- \
  --ignored --nocapture --test-threads=1

cargo run --locked --release --bin koikari -- \
  verify-targets /path/to/combined 5000000 --max-states 2000000
```

`verify-targets` 从首次到达各入口/选项的合法状态分叉，回放由自然终局进度调度。已有结果为 `targets_complete=true`、`complete=false`，零 direct probe、零未遍历目标或 blocker。`verify-all` 用于有预算的组合探索，预算耗尽必须报告失败，不能改写成完成。
